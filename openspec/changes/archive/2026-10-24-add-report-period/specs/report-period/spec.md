# Spec Delta

## Purpose

Позволяет одному отчёту строиться за разные периоды: пользователь выбирает период при запуске из бота, а запуски по расписанию берут период по умолчанию из описания отчёта.

## ADDED Requirements

### Requirement: Переменные периода в параметрах
В выражениях параметров запросов отчёта (значения `params`, которые начинаются с `=`) SHALL быть доступны переменные `period_from` и `period_to` типа timestamp: начало периода включительно и конец не включительно. Значения, не использующие эти переменные, SHALL вычисляться как раньше.

#### Scenario: Параметр с периодом
- **WHEN** у запроса `params = {"from": "=period_from"}`, а запуск идёт за `yesterday`
- **THEN** в запрос подставляется начало вчерашнего дня в том же текстовом формате, что даёт `=today()`

#### Scenario: Параметр без периода
- **WHEN** у запроса `params = {"d": "=today()"}`
- **THEN** значение то же, что до изменения

### Requirement: Набор периодов
Период MUST быть одним из: `today` — [начало сегодняшнего дня, начало завтрашнего); `yesterday` — [начало вчерашнего дня, начало сегодняшнего); `week` — [начало дня 7 дней назад, начало сегодняшнего); `month` — [1-е число прошлого месяца, 1-е число текущего). Время считается в часовом поясе процесса бота.

#### Scenario: Прошлый месяц в январе
- **WHEN** 15 января запуск идёт за `month`
- **THEN** `period_from` — 1 декабря прошлого года 00:00, `period_to` — 1 января 00:00

### Requirement: Период по умолчанию
У отчёта SHALL быть поле `default_period` (один из четырёх периодов, по умолчанию `today`), которое задаётся и экспортируется в JSON-описании отчёта. Запуски по cron и кнопкой «▶️ Запустить» SHALL использовать его. Неизвестное значение MUST отклоняться при `ctl validate` и `ctl apply`.

#### Scenario: Ежедневный отчёт за вчера
- **WHEN** у отчёта `default_period = "yesterday"` и cron в 09:00
- **THEN** запрос получает `period_from` — начало вчерашнего дня

#### Scenario: Опечатка
- **WHEN** `ctl apply` получает отчёт с `default_period = "weak"`
- **THEN** загрузка отклоняется с ошибкой про `default_period`

### Requirement: Выбор периода в боте
Для отчёта, у которого хотя бы одно значение `params` содержит `period_`, получение отчёта в чат (кнопка «📤 Получить» в админке и запуск отчёта в ЛК) SHALL сначала предлагать выбор периода: «Сегодня», «Вчера», «Неделя», «Месяц». Отчёт генерируется за выбранный период. Для остальных отчётов выбор MUST NOT показываться.

#### Scenario: Пользователь берёт отчёт за неделю
- **WHEN** пользователь в ЛК выбирает отчёт с `period_from` в params и нажимает «Неделя»
- **THEN** ему приходит отчёт, собранный с периодом `week`

#### Scenario: Отчёт без периода
- **WHEN** пользователь выбирает отчёт, где `period_` нигде не используется
- **THEN** отчёт запускается сразу, без выбора периода
