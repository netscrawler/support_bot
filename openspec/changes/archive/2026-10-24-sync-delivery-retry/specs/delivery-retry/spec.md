# Spec Delta

## Purpose

Не даёт короткому сбою сети или канала доставки потерять отчёт: неудавшаяся отправка повторяется на месте, и итог доставки известен до того, как запуск записывается в журнал.

## ADDED Requirements

### Requirement: Повтор отправки
Отправка отчёта получателю в Telegram, Max, по SMTP и на SMB SHALL повторяться после временной ошибки: до 3 повторов с паузами из конфига (по умолчанию 1s, 5s, 15s). Итог отправки (успех с ID сообщения или последняя ошибка) SHALL быть известен вызывающему коду до возврата из отправки.

#### Scenario: Разовый сбой сети
- **WHEN** первая попытка отправки в Telegram упала по таймауту, а вторая прошла
- **THEN** отправка считается успешной, ID сообщения сохраняется как у обычной отправки

#### Scenario: Канал недоступен
- **WHEN** все 4 попытки отправки по SMTP упали с сетевой ошибкой
- **THEN** отправка возвращает последнюю ошибку, всего сделано 4 попытки

### Requirement: Без повтора безнадёжных ошибок
Отправка MUST NOT повторяться после ошибок, которые повтор не исправит: ответы Telegram 400, 401, 403, 404; ответ SMTP с кодом 5xx; отмена или истечение контекста.

#### Scenario: Бот удалён из чата
- **WHEN** Telegram ответил 403
- **THEN** отправка сразу возвращает ошибку, повторов нет

#### Scenario: Остановка бота во время паузы
- **WHEN** контекст отменён во время паузы между попытками
- **THEN** отправка сразу возвращает ошибку контекста

### Requirement: Лимит Telegram
При ответе Telegram 429 пауза перед повтором SHALL быть равна `retry_after` из ответа, если он не больше 60 секунд. Если больше, отправка MUST завершаться ошибкой без повтора.

#### Scenario: Too Many Requests
- **WHEN** Telegram ответил 429 с `retry_after = 3`
- **THEN** следующая попытка выполняется через 3 секунды

### Requirement: Повтор не дублирует уже отправленное
Если отчёт отправляется несколькими сообщениями (несколько документов), повтор SHALL касаться только того сообщения, которое не ушло.

#### Scenario: Второй из трёх файлов не ушёл
- **WHEN** при отправке трёх документов вторая отправка упала один раз
- **THEN** повторно отправляется только второй документ, каждый файл приходит один раз

### Requirement: Повтор удаления
Удаление ранее отправленного сообщения в Telegram и Max SHALL повторяться по тем же правилам, что и отправка.

#### Scenario: Сбой при удалении
- **WHEN** первая попытка удалить сообщение упала по сети, вторая прошла
- **THEN** удаление считается успешным
