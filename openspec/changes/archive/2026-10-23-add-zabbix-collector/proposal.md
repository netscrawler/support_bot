# Proposal

## Why

В отчёты нужны данные из Zabbix (7.4): проблемы, события, история и тренды метрик, хосты и прочее, что отдаёт его API. Сейчас бот этого не умеет. Пользователю нужна возможность вытащить любые данные на чтение, а не фиксированный набор отчётов, поэтому коллектор делается как универсальный read-only вызов API.

## What Changes

- Новый тип запроса `zabbix`. В `card_uuid` хранится имя Zabbix из новой секции конфига `zabbix`. В `queries.query` лежит JSON `{"method": "<сервис>.get", "params": {...}}`, в `params` — значения для подстановки `${name}`.
- Разрешены только методы `*.get`. Любой другой метод отклоняется до отправки запроса.
- `${name}` подставляется только в строковые значения JSON, с экранированием. Если значения нет, это ошибка.
- Каждый элемент `result` становится строкой, вложенные объекты разворачиваются в колонки (`hosts.0.host`). Скалярный результат (`countOutput`) даёт одну строку `{result: …}`. Значения отдаются как есть, без перевода кодов и времени.
- Ошибка JSON-RPC и HTTP-статус вне 2xx завершают запрос ошибкой. Токен в текст ошибки не попадает.
- Новая секция конфига `zabbix: {<имя>: {url, token, timeout}}`. Токен маскируется в логах, неверная запись роняет старт.
- Коллектор доступен из Lua: `collector.zabbix.collect(name, query_json, params)`.

## Capabilities

### New Capabilities
- `zabbix-collector`: сбор данных отчёта из Zabbix, описанного в конфиге, через read-only методы `*.get` его API, в том числе из Lua-скриптов.

## Impact

- Код: новый пакет `internal/collector/zabbix`, ветка `zabbix` в `internal/collector/collector.go`, константа в `internal/models/report.go`, секция `Zabbix` и маскирование в `internal/config/config.go`, `internal/app/module_collectors.go`, `internal/app/module_report.go` (Lua), `cmd/live-server/main.go`, `config/config.example.yaml`.
- БД: без изменений.
- Безопасность: запросы отчётов и Lua-скрипты получат доступ на чтение ко всему, что разрешено токену Zabbix. Права ограничиваются белым списком `*.get` в боте и ролью пользователя токена. Перед archive обязателен `/security-review`.
- Зависимости: новых нет.
- Вне объёма: готовые режимы (problems/history с фильтрами), перевод кодов severity и epoch в читаемый вид, передача запроса Lua-таблицей, методы записи, доступ к Zabbix через Grafana.
