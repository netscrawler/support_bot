# public-report-links Specification

## Purpose

Управляет публичными ссылками, по которым отчёт генерируется без аутентификации: позволяет ограничить их срок жизни, создавать и отзывать их без ручных SQL-запросов.

## Requirements

### Requirement: Срок действия ссылки
Публичная ссылка SHALL иметь необязательный момент истечения. Ссылка без срока SHALL работать бессрочно. Запрос по ссылке, срок которой истёк, MUST получать `410 Gone`, отчёт при этом MUST NOT генерироваться.

#### Scenario: Ссылка без срока
- **WHEN** открывают ссылку, созданную без `-ttl`, через год после создания
- **THEN** отчёт генерируется и отдаётся, как сейчас

#### Scenario: Истёкшая ссылка
- **WHEN** открывают ссылку, у которой срок истёк минуту назад
- **THEN** ответ 410, обращений к источникам данных нет

#### Scenario: Несуществующая ссылка
- **WHEN** открывают корректный UUID, которого нет среди ссылок
- **THEN** ответ 404

### Requirement: Существующие ссылки
Ссылки, созданные до этого изменения, SHALL остаться бессрочными.

#### Scenario: Накатка миграции
- **WHEN** миграция применена на БД с существующими ссылками
- **THEN** все они продолжают отдавать отчёт

### Requirement: Создание ссылки через CLI
`sbot ctl link create` SHALL создавать ссылку на отчёт по его имени, с необязательным сроком действия (длительность Go, например `168h`), и печатать UUID и путь `/api/v1/public/report/{uuid}`. Для несуществующего отчёта команда MUST завершаться ошибкой без создания ссылки.

#### Scenario: Ссылка на неделю
- **WHEN** `sbot ctl link create -report daily -ttl 168h`
- **THEN** напечатан UUID, ссылка работает 7 дней, а потом отвечает 410

#### Scenario: Опечатка в имени отчёта
- **WHEN** `-report` указывает на несуществующий отчёт
- **THEN** команда завершается с ненулевым кодом, ссылка не создана

### Requirement: Список и отзыв через CLI
`sbot ctl link list` SHALL выводить ссылки (UUID, отчёт, создана, истекает, состояние активна/истекла), с необязательным фильтром по отчёту. `sbot ctl link revoke <uuid>` SHALL немедленно делать ссылку недействительной, после чего запросы по ней MUST получать 410.

#### Scenario: Отзыв утёкшей ссылки
- **WHEN** выполняется `sbot ctl link revoke <uuid>` для активной ссылки
- **THEN** следующий запрос по ней получает 410, а в `link list` она показана как истёкшая

#### Scenario: Отзыв неизвестной ссылки
- **WHEN** UUID не найден
- **THEN** команда завершается с ненулевым кодом и сообщением, что ссылка не найдена
